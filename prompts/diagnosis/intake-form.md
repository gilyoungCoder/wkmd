# 외모진단 접수 항목 (고객에게 받을 것)

> 결제 후 고객에게 보내는 질문지. Tally/구글폼으로 만들 때도 이 항목 그대로.
> 진단서 품질 = 입력 품질. 사진 가이드가 특히 중요.

## 사진 (필수 3장)
1. **정면 상반신** — 밝은 곳, 정면 시선, 민얼굴에 가까운 상태 권장
2. **정면 전신** — 평소 옷차림, 거울샷 OK (폰이 얼굴 가려도 됨)
3. **측면 전신** — 자연스럽게 선 자세
- 안내문구: "잘 나온 사진보다 **평소 모습** 그대로가 정확한 진단에 도움됩니다"

## 기본 정보
- 이름(닉네임 가능) / 나이대 / 키 / 몸무게(선택) / 직업 또는 주요 생활 환경

## 스타일 질문
1. 지금 스타일에서 **가장 바꾸고 싶은 것** 하나는?
2. 옷을 살 때 가장 어려운 점은?
3. 평소 자주 입는 스타일 (사진 추가 가능)
4. 동경하는 스타일·연예인·인물 (있다면)
5. 절대 못 입겠다 하는 것 (스키니, 밝은 색 등)
6. 한 시즌 옷 예산은 대략?
7. 진단서에서 꼭 다뤄줬으면 하는 것 (자유)

## 동의
- 사진은 진단 목적으로만 사용, 진단 완료 후 파기 ☑️
- (마케팅 활용은 별도 동의 — 기본 미체크)
