# 유튜브 포맷 (릴스/쇼츠 + 롱폼 스크립트)

## A. 쇼츠/릴스 스크립트 (30~60초)

구조 (촬영 그대로 쓸 수 있게):
```
[훅 0~3초]   멈추게 하는 한 문장 (화면 텍스트 동일)
[문제 3~10초] 공감 상황 — "이런 적 있으시죠"
[핵심 10~40초] 포인트 1~3개, 각각 화면지시 포함
[마무리 40~60초] 한 줄 정리 + 다음 행동 (팔로우/카페/테스트)
```
- 출력 형식: **대사 / [화면: 촬영·자막 지시] / (톤 지시)** 3열 구분
- 말 자막 기준 한 문장 12자 내외로 끊기 (모바일 자막 가독)
- 마무리 CTA는 3개 중 1개만, 로테이션 (매번 판매 ✗)

## B. 롱폼 스크립트 (5~12분)

구조:
```
1. 콜드오픈 (결론 티저 15초) — "오늘 영상 끝까지 보면 ○○를 알게 됩니다"
2. 인트로 (브랜드 한 줄 + 오늘 주제)
3. 본론 챕터 2~4개 — 챕터마다: 주장 → 근거/시연 → 실예시(동행쇼핑 에피소드)
4. 요약 + CTA (카페/테스트/다음 영상)
```
- 챕터별 예상 시간 표기, B-roll(삽입 화면) 제안 포함
- 검색 키워드를 제목·도입부에 자연스럽게 (유튜브 SEO)

## C. 함께 뽑는 부속물 (스크립트 요청 시 자동 포함)

- 제목 후보 5개 (검색형 2 + 후킹형 3)
- 썸네일 문구 2~3안 (6자 내외 큰 글씨 + 보조 문구)
- 설명란 (키워드 포함 3~4문장 + 카페/테스트 링크 자리)
- 태그 10개

## 재창작 룰 (동일 적용)
- 트렌드 영상에서 가져오는 건 **주제·구성 아이디어만** — 대사·자막·편집을 복제하지 않음
- 위캔드무드 실제 경험(동행쇼핑·진단 에피소드) 최소 1개 포함 — 이게 차별점
- 의료·과장 표현 금지는 영상에서도 동일
