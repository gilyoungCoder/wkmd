# 블로그 포맷 (네이버 블로그 기준)

## 구조
1. **제목**: 검색 키워드 포함 + 구체적 약속 (예: "남자 여름 바지, 3만원대에서 실패 안 하는 기준 3가지")
   - 후보 2개 제시 (검색형 / 후킹형)
2. **도입 (3~5문장)**: 독자의 상황 공감 → 이 글이 해결할 것 예고
3. **본문**: 소제목 2~4개로 분할. 소제목마다:
   - 핵심 주장 → 이유 → 실제 예시(아이템/장면) → 한 줄 정리
4. **마무리**: 요약 3줄 + 자연스러운 서비스 연결 1문장 (강요 ✗) + 카페/테스트 링크

## 형식 규칙
- 1,500~2,500자. 문단은 3~4문장 이내로 짧게 (모바일 가독성)
- 검색 키워드를 제목·첫 문단·소제목에 자연스럽게 (스팸성 반복 ✗)
- 이미지 들어갈 위치를 `[이미지: 설명]`으로 표시 (선우님이 채움)

## 톤
- brand/tone.md 따름. 블로그는 가장 차분하고 신뢰 중심 채널 — 근거와 경험을 충분히.
