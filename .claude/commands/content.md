위캔드무드 콘텐츠 제작 워크플로. 인자: $ARGUMENTS (예: "쓰레드 여름바지" — 채널/소재. 비어 있으면 물어본다)

## 절차

1. **소재 확인**:
   - 인자에 소재가 있으면 그걸 사용
   - 없으면 최신 `outputs/trends/소재보드_*.md`를 읽고 🔥 우선순위 소재들을 보여주며 고르게 한다
   - 소재 보드도 없으면: "먼저 `/trend`로 소재를 모을까요, 아니면 주제를 직접 말씀해주시겠어요?"

2. **채널 확인**: 쓰레드 / 블로그 / 인스타 중 (인자에 없으면 질문). 복수 선택 가능.

3. **작성**: `copywriter` 에이전트에 위임. 전달할 것:
   - 소재 + 위캔드무드 각도 (소재 보드의 해당 항목)
   - 채널별 포맷: `prompts/content/{channel}.md`
   - 자막 원문이 있으면 참고용으로 (단, 재창작 룰 — 표현 복제 금지)
   - **선우님 경험 한 줄**이 없으면 작성 전에 1개 질문: "이 주제 관련해서 실제 고객/쇼핑에서 겪은 에피소드 있으세요? 한 줄이면 됩니다" (품질이 크게 달라짐)

4. **결과**: 완성본 보여주기 + `outputs/content/YYYY-MM-DD_채널_제목.md` 저장
   - 피드백 받으면 즉시 수정. 2회 이상 같은 방향 피드백이 나오면 `brand/tone.md`에 규칙으로 반영할지 제안.
