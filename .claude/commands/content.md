위캔드무드 콘텐츠 제작 워크플로. 인자: $ARGUMENTS (예: "쓰레드 여름바지" — 채널/소재. 비어 있으면 물어본다)

## 절차

1. **소재 확인**:
   - 인자에 소재가 있으면 그걸 사용
   - 없으면 최신 `outputs/trends/소재보드_*.md`를 읽고 🔥 우선순위 소재들을 보여주며 고르게 한다
   - 소재 보드도 없으면: "먼저 `/trend`로 소재를 모을까요, 아니면 주제를 직접 말씀해주시겠어요?"

2. **채널 확인**: 쓰레드 / 블로그 / 인스타 / **유튜브(쇼츠·롱폼 스크립트)** / 카페(정보글·Q&A) 중 (인자에 없으면 질문). 복수 선택 가능.
   - 유튜브는 스크립트(대사+화면지시) + 제목 5안 + 썸네일 문구 + 설명란 + 태그까지 한 세트로 — `prompts/content/youtube.md`
   - 카페 글은 B2C 본진용 — 광고 티 없이 정보·경험 중심, 마지막에 가벼운 서비스 언급만

3. **경험 자동 결합** (작성 전 필수):
   - 먼저 `brand/experiences.md`(경험 은행)에서 소재와 태그·내용이 맞는 에피소드 검색
   - **있으면**: "EXP-NNN(○○ 에피소드) 활용할게요" 알리고 바로 사용 — 질문 생략. 단, 사용 이력에 같은 채널 최근 사용이 있으면 다른 에피소드 우선
   - **없으면**: 간단 질문으로 자동완성 — "이 주제 관련 기억나는 장면 하나만요. 한 줄이면 됩니다" → 답이 짧으면 후속 1~2개만 (장면 구체화 / 결과) → 답을 EXP 형식으로 정리해 **경험 은행에 자동 저장** (다음부턴 안 물어봄)
   - 에피소드 없이도 쓰겠다고 하면 일반 작성 (단, 경험 기반 글이 성과가 좋다는 점 한 번 언급)

4. **작성**: `copywriter` 에이전트에 위임. 전달할 것:
   - 소재 + 위캔드무드 각도 (소재 보드의 해당 항목) + 선택된 에피소드
   - 채널별 포맷: `prompts/content/{channel}.md`
   - 자막 원문이 있으면 참고용으로 (단, 재창작 룰 — 표현 복제 금지)
   - 작성 후 경험 은행의 해당 EXP에 사용 이력(날짜·채널) 기록

5. **결과**: 완성본 보여주기 + `outputs/content/YYYY-MM-DD_채널_제목.md` 저장
   - 피드백 받으면 즉시 수정. 2회 이상 같은 방향 피드백이 나오면 `brand/tone.md`에 규칙으로 반영할지 제안.
