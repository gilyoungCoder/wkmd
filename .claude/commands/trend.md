유튜브 트렌드 스캔 → 소재 추출 워크플로를 실행한다. 인자: $ARGUMENTS (국가코드, 비면 전체)

## 절차

1. **스캔 실행** (인자가 없으면 `kr,us,jp,fr,uk,it` 전체 — 5~10분 걸린다고 사용자에게 미리 알리기):
   ```
   python3 scripts/trend_scan.py --countries {인자 또는 전체}
   ```
   - 전체 국가면 백그라운드 실행 권장. 출력 마지막 줄 = 리포트 경로.
   - 오늘 날짜 리포트가 이미 `data/trends/`에 있으면 "이미 오늘 스캔이 있는데 다시 돌릴까요?" 확인.

2. **자막 보강 (선택)**: 리포트 상위 영상 중 velocity 1~3위에 대해
   ```
   python3 scripts/fetch_subs.py <URL1> <URL2> <URL3>
   ```
   → 논점 구조 파악용 (실패해도 진행 — 제목·메타데이터만으로 충분히 가능)

3. **소재 추출**: `trend-analyst` 에이전트에 위임 — 리포트(+자막)를 읽고 소재 보드 10개 작성
   → `outputs/trends/소재보드_YYYY-MM-DD.md`

4. **사용자에게 보고**: 이번 주 픽 추천 3개를 요약해 보여주고, "어떤 소재로 콘텐츠를 만들까요? `/content`로 이어가시면 됩니다" 안내.

## 주의
- 스크립트 실패 시(네트워크 등) 에러 원문을 보여주지 말고 한 줄로 설명 + 재시도 1회
- 키워드를 바꾸고 싶다는 요청이면 `brand/trend-keywords.json` 수정 후 재실행
