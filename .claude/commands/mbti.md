패션 MBTI(WKND MOOD TEST) 타입 콘텐츠 디벨롭. 인자: $ARGUMENTS (타입 코드, 예: SMTH. 비면 어떤 타입인지 질문)

## 컨텍스트
- 테스트 라이브: https://wkmd.vercel.app/test (12문항 → 4축 → 16타입)
- 타입 코드는 4글자 (각 축에서 한 글자씩)
- 결과 콘텐츠는 웹사이트 Sanity Studio에서 편집됨 — 여기서 만든 디벨롭본을 선우님이 Studio에 붙여넣는 구조

## 절차
1. **현재 상태 확인**: WebFetch로 `https://wkmd.vercel.app/test/result/{코드}` 를 읽어 현재 카피(이름/태그라인/설명/키워드/추천 서비스) 파악
2. `fashion-director` 에이전트에 위임 — 디벨롭 항목:
   - 타입 설명: 현재 카피를 더 구체적·공감되게 (이 타입인 사람이 "어 이거 나네" 하는 디테일)
   - **예시 스타일 가이드**: 이 타입의 시그니처 아이템 5개 + 대표 룩 2~3개 (실구매 가능 기준)
   - **예시 사진 가이드**: 어떤 무드의 사진을 쓰면 되는지 (촬영/선별 기준 — 선우님이 사진 고를 때 사용)
   - 추천 서비스 연결 문구 (이 타입 → 동행쇼핑/진단으로 자연스럽게)
3. 결과 저장: `outputs/content/mbti_{코드}_YYYY-MM-DD.md`
4. 안내: "Studio(https://wkmd.vercel.app/studio → MBTI · Result Types)에서 해당 타입에 붙여넣으면 사이트에 반영됩니다"

## 16타입 전체 작업 요청이면
한 번에 다 하지 말고 4개씩 끊어서 진행 (품질 유지), 진행 상황을 체크리스트로 보여준다.
