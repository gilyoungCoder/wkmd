선우님 Mac에서 **"위캔드무드를 아는 Claude"**가 돌아가게 만든다.
단순 설치가 아니라, 브랜드 컨텍스트가 주입된 에이전트 환경을 만드는 게 핵심.

## 결과물 체크리스트

- [ ] 선우님 Mac: VSCode (선우님 설치) + Homebrew + Node.js + Claude Code (영환 설치)
- [ ] Claude 구독/플랜 결정 (Pro vs Max — 사용량에 따라; 2~4단계 콘텐츠 작업량 고려 시 Pro로 시작 권장)
- [ ] **브랜드 컨텍스트 파일 세트** (이 레포 `brand/` 폴더에서 관리, 선우님 Mac에 복사):
  - `CLAUDE.md` — 위캔드무드가 누구인지, 무엇을 하는지, 절대 하지 말 것
  - `brand/tone.md` — 톤앤매너 가이드 (프리미엄·절제·남성 타깃 존댓말 등, 선우님과 함께 작성)
  - `brand/services.md` — 서비스 목록·가격·프로세스 (진단서/콘텐츠 생성 시 참조)
  - `brand/audience.md` — 타깃 고객 정의 (B2C 개인 / B2B 브랜드·기업)
- [ ] 선우님용 **시작 프롬프트 키트** — 자주 쓸 작업별 템플릿 5~10개 (인스타 캡션, 블로그 글, 고객 응대 등)
- [ ] 30분 온보딩 세션 — 기본 사용법 + "질문 잘 하는 법" 맛보기 ([05-skills-track.md](05-skills-track.md) §10 연계)

## 세팅 절차 (영환 작업 순서)

1. **선행**: 선우님 VSCode 설치 확인
2. Homebrew → Node.js(LTS) → `npm install -g @anthropic-ai/claude-code`
3. Claude 계정 로그인 (선우님 계정 — 결제 수단 선우님)
4. 작업 폴더 `~/wkndmood/` 생성, 이 레포 clone (선우님 GitHub 계정 초대 후)
5. `CLAUDE.md` + `brand/` 배치 → Claude가 항상 브랜드 컨텍스트를 읽고 시작
6. 테스트: "인스타 캡션 하나 써줘" → 톤이 맞게 나오는지 확인하며 `brand/tone.md` 보정

## 품질 극대화 포인트 (왜 이 구조인가)

- **컨텍스트 > 모델**: 같은 Claude라도 브랜드 정보를 알고 쓰는 것과 모르는 것의 차이가 품질의 80%.
  `CLAUDE.md`에 브랜드 정보를 박아두면 매번 설명할 필요 없이 항상 품질이 일정해짐.
- **금지 목록이 중요**: "하지 말 것"(과장 광고 표현, 의료성 표현, 톤 깨지는 이모지 남발 등)을 명시해야 AI 특유의 어색함이 사라짐.
- **재사용 가능한 프롬프트**: 잘 나온 프롬프트는 버리지 말고 이 레포 `prompts/`에 누적 → 2~4단계 자산이 됨.
