# 2차 트랙. 역량 강화 · 보조 (1~4단계와 병행)

> 시점: **0-A AI 세팅 완료 후 수시** · 형식: 짧은 가이드 + 실습 세션 중심
> 목표: 선우님이 영환 없이도 도구를 직접 굴릴 수 있는 상태

## [5] 정보 크롤링 — 트렌드·경쟁사·소재 수집

**3단계 파이프라인의 입력단** ([03-content-pipeline.md](03-content-pipeline.md) §① 과 동일 작업).

- 영환: 수집 스크립트 제공 + **방법 안내** (소스 추가/키워드 변경을 선우님이 직접)
- 난이도 낮은 순서로: ① 네이버 데이터랩·검색트렌드 (웹에서 클릭) → ② RSS 구독 정리 → ③ 스크립트 실행 (터미널 명령 1줄)
- ⚖️ 약관·저작권: 공개 데이터의 주제·반응 수준만, 로그인 필요 영역·대량 수집 금지

## [9] PPT 디자인 — 제안서·포트폴리오 슬라이드 템플릿화

B2B 영업([01-website-b2b-b2c.md](01-website-b2b-b2c.md))과 직결되는 자산.

- 결과물: 위캔드무드 마스터 템플릿 1벌 (표지/목차/케이스/가격/마무리 — 로고·컬러·서체 통일)
- 방법: Claude로 슬라이드 구조·문구 생성 → Keynote/PPT 마스터에 부어넣기. (HTML 슬라이드 → PDF 루트도 시연)
- 진단서·스타일링 PDF([02](02-diagnosis-funnel.md)·[04](04-review-system.md))와 디자인 시스템 공유 → **브랜드 문서가 전부 한 식구처럼** 보이게

## [10] 질문 잘 하는 법 — 프롬프트 스킬

모든 단계의 곱하기 계수. 0-A 온보딩에서 맛보기 → 이후 심화.

핵심 4원칙 (선우님용 치트시트로 제공):
1. **역할+상황 먼저**: "너는 위캔드무드의 카피라이터야. 30대 남성 고객 대상…"
2. **결과물 형태 지정**: "인스타 캡션, 3문장, 해시태그 5개, 이모지 없이"
3. **예시 1개 제시**: 잘 된 결과물 하나 보여주면 품질 급상승 (few-shot)
4. **한 번에 한 가지 + 반복 개선**: 첫 결과에 "더 절제된 톤으로" 같은 피드백을 2~3회

+ 잘 나온 프롬프트는 이 레포 `prompts/`에 저장하는 습관 (자산화)

## [12] 사진 보정 피드백 — 촬영·보정 결과 AI 점검

- 워크플로: 보정본을 Claude에 첨부 → 점검 프롬프트 (노출/피부톤/색감 일관성/크롭·시선 흐름/브랜드 무드 적합)
- 결과물: **보정 점검 프롬프트 템플릿** (`prompts/photo-feedback.md`) + 보정 전후 비교 요청 패턴
- 활용: 포트폴리오 업로드 전 셀프 QA, 후기 PDF용 사진 선별

## 진행 방식 제안

각 항목당 **1회 세션(30~60분) + 치트시트 1장** 형식. 1~4단계 주간 작업과 겹칠 때 자연스럽게:
- W3(퍼널 주간) → [10] 프롬프트 스킬 (진단서 만들며 실습)
- W4(콘텐츠 주간) → [5] 크롤링 (파이프라인 입력단 만들며 실습)
- W5(리뷰 주간) → [9] PPT + [12] 사진 보정 (PDF 템플릿 만들며 실습)
