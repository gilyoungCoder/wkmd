# 2단계. 외모진단 · 패션MBTI 퍼널

> 목표 기한: **6/22 (월)**
> 합의된 전략: MBTI = 무료·자동 (미끼) / 상세 외모진단 = 유료·**수동** 제작
> 왜 수동인가: 자동 외모진단은 토큰비로 적자 위험. 무료 토큰 지원은 법인+VC 시리즈A 이상에서만 가능 → 그때까지 수동.

## 퍼널 전체 그림

```
 [유입]            [무료 후킹]              [전환]                [유료 상품]
 인스타/카페   →   패션 MBTI 테스트    →   결과 페이지 하단     →   상세 외모진단 (유료)
 블로그/검색       (12문항, 자동)          "내 진단은?" CTA         수동 제작, "1주일 내" 약속
                       │                                              │
                       └── 결과 공유(OG) → 바이럴 재유입               └── 만족 → 후기(4단계) → 카페 정착
```

핵심: MBTI 결과가 **"재미"**로 끝나지 않고 **"나를 더 알고 싶다"**로 이어지게 결과 카피와 CTA를 설계.

## A. 무료 패션 MBTI (데모 이미 있음 → 다듬기)

현재: https://wkmd.vercel.app/test — 12문항 → 4축 → 16타입, 결과별 OG 이미지, Sanity에서 전 문항·결과 편집 가능.

- [ ] **16타입 결과 카피 다듬기** (영환 — AI 활용해 초안 → 선우님 검수·위캔드무드화)
  - 각 타입: 한 줄 정체성 / 강점 / 스타일 키워드 / **추천 서비스 연결** (퍼널의 핵심 문장)
- [ ] 결과 페이지 하단에 **외모진단 CTA 블록** 추가: "타입은 시작일 뿐 — 당신 얼굴·체형 기준 진짜 진단 받기"
- [ ] 공유 동선 점검 (카카오톡 공유 시 OG 이미지·문구)

## B. 유료 외모진단 (수동 제작 상품화)

### 운영 모델

| 항목 | 설계 |
|---|---|
| 고객 약속 | **"1주일 내 완료"** — 여유 버퍼 + 정성 케어 느낌 |
| 실제 제작 | 프롬프트 품질을 높여 **건당 30분 내** |
| 작업 방식 | **요일 정해 일괄 작업** (배치) — 예: 매주 수요일 저녁. 컨텍스트 전환 없이 N건 연속 처리 |
| 손익 | 토큰비 건당 ~수백 원 수준 (수동·Claude 구독 내) vs 진단 가격 → 마진 구조 안전 |

### 고객 플로우 (구축 대상)

1. 결제 — 스마트스토어 or 카카오 (기존 채널 재사용, 선우님 확정)
2. **접수 폼** — 사진 업로드(정면/측면/전신) + 기본 정보(키/체형/고민/선호) + 개인정보 동의
   - 구현: Tally/Google Form으로 시작 (무료·사진 업로드 가능) → 추후 사이트 내장
3. 제작 — 선우님이 배치 요일에 **진단 프롬프트 키트**로 생성 → PDF 출력 → 검수·터치업
4. 발송 — 이메일/카톡 채널로 PDF 전달 + 후기 요청 멘트 (4단계 연결)

### 영환 결과물

- [ ] **진단 프롬프트 키트** (`prompts/diagnosis/`) — 고품질 고정 구조:
  - 입력: 고객 폼 답변 + 사진 → 출력: 섹션별 진단 (퍼스널컬러 방향 / 얼굴형·인상 / 체형 보완 / 스타일 방향 3종 / 피해야 할 것 / 쇼핑 가이드)
  - 톤: `brand/tone.md` 기반, 단정적이되 따뜻하게. 의료·시술 권유성 표현 금지.
- [ ] **PDF 템플릿 고급화** — 표지/목차/섹션 디자인 (위캔드무드 로고·컬러), HTML→PDF 또는 Keynote 템플릿. "받는 순간 가격이 납득되는" 만듦새가 목표.
- [ ] 접수 폼 세팅 + 결제→폼 안내 자동화 문구
- [ ] MBTI 결과 → 진단 구매 CTA 연결 (사이트 작업)

### 선우님 확정 필요

- [ ] 진단 가격 / 결제 수단 (스마트스토어 vs 카카오 vs 둘 다)
- [ ] 배치 작업 요일
- [ ] 진단서 샘플 1건 함께 만들어보기 (품질 기준 합의용 — **킥오프 때 같이 1건 제작 권장**)
