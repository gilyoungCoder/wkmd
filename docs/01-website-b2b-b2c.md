# 1단계. 웹사이트 B2B / B2C 분리 구조 [최우선]

> 목표 기한: 자료 전달 6/8 → **구축 6/15 (일)**
> 왜: 타깃이 다른데(개인 고객 vs 브랜드·기업) 한 페이지에 섞이면 둘 다 흐려짐

## 핵심 콘셉트

메인 랜딩에서 **갈림길**. 둘 다 보여주되, 클릭하면 사이트가 갈라진다.

```
                    ┌─────────────────────┐
                    │   메인 랜딩 (/)      │
                    │  브랜드 무드 + 갈림길  │
                    └──────┬───────┬──────┘
                 FOR YOU   │       │   FOR BRANDS
              ┌────────────┘       └────────────┐
              ▼                                 ▼
        /b2c (개인)                        /b2b (비즈니스)
   "당신의 스타일"                     "브랜드를 위한 비주얼 디렉팅"
   - 서비스 소개 (라이트하게)           - 브랜드 스타일링 포트폴리오
   - 패션 MBTI 테스트 (후킹)           - 대기업 제휴 실적
   - 후기 하이라이트 (4단계 연동)       - 소상공인 유니폼 큐레이팅
   - ▶ 네이버 카페로 유입 (메인 CTA)    - 중국 계약 등 케이스 스터디
   - ▶ 외모진단 (2단계 퍼널)           - ▶ 제휴/프로젝트 문의 폼
```

### 분리 원칙

- **B2C는 카페로 보낸다**: 개인 스타일링 상세는 메인에서 빼고 네이버 카페 안쪽으로.
  사이트의 B2C 역할 = 무드 전달 + MBTI 후킹 + 카페 유입. (커뮤니티=신뢰 자산은 카페에 쌓음)
- **B2B는 사이트가 본체**: 큰 건(브랜드/대기업/유니폼) 대상 포트폴리오. 격식 있는 톤, 실적 중심, 문의 폼 직결.
- 헤더/푸터는 공유하되, B2B 진입 시 네비게이션이 B2B 메뉴로 전환 (혼선 방지).

## 사이트맵 (안)

| 경로 | 내용 | 기존 코드 재사용 |
|---|---|---|
| `/` | 새 갈림길 랜딩 (풀스크린 2분할 or 히어로+듀얼 CTA) | 인트로 모션·모션 시스템 재사용, 레이아웃 신규 |
| `/b2c` | 개인용 허브: 서비스 라이트 소개 + MBTI CTA + 후기 + 카페 버튼 | 기존 홈/컨설팅 페이지 재구성 |
| `/b2c/test` (또는 `/test` 유지) | 패션 MBTI (기존 그대로) | ✅ 100% 재사용 |
| `/b2b` | 비즈니스 허브: 포트폴리오 + 실적 + 케이스 | 🆕 신규 (0-B 자료 필수) |
| `/b2b/work/[slug]` | 케이스 스터디 상세 (중국 계약 등) | DragGallery·라이트박스 재사용 |
| `/b2b/contact` | 제휴 문의 폼 | 기존 /contact + Resend 재사용 |
| `/brand` `/faq` | 공통 (양쪽에서 링크) | ✅ 재사용 |
| `/studio` | Sanity CMS (B2B 콘텐츠도 편집 가능하게 스키마 확장) | ✅ 확장 |

## 보류 사항 (지금 안 함)

- B2B **중국 유입** 방향 미결정 → 케이스 스터디로만 노출, 중국어 대응 없음
- **영문판** → 법인 개설 후 플랫폼 개발 단계에서. (현재 i18n 토글 코드는 존재 — 그때 재활용)
