## 📦 사이트용 자료 .zip (AI 세팅 완료 후 전달)

폴더 구조 이대로 담아주시면 바로 작업 들어갈 수 있습니다:

```
wkmd_assets.zip
├── logo/          ← 로고 원본 (AI/PSD/SVG 등 원본 파일 + 흰/검 버전)
├── photos/        ← 사진 원본 전부 (보정본·원본 구분되면 폴더로)
│   ├── b2c/       ← 개인 컨설팅·동행쇼핑·촬영 결과물
│   └── b2b/       ← 브랜드 작업·기업 프로젝트 관련
├── copy/          ← 넣을 문구·글귀 (메모장/한글/워드 아무거나)
│   ├── b2b용.txt  ← B2B 페이지에 들어갈 소개·강점·실적 문구
│   └── b2c용.txt
└── portfolio/     ← 중국 계약 등 포트폴리오 PDF
```

### 각 항목 메모

| 항목 | 왜 필요한가 | 비고 |
|---|---|---|
| 로고 원본 | 현재 사이트는 비트맵 추적본 사용 중 — 원본 있으면 화질·인트로 모션 품질 ↑ | 벡터(AI/SVG)면 최고 |
| 사진 전부 | B2B/B2C 분리 시 페이지가 2배 — 기존 260장 외 추가분 필요 | 고해상도 원본, 사이트용 리사이즈는 영환이 |
| 문구·글귀 | **B2B 페이지는 콘텐츠가 0에서 시작** — 문구 없으면 못 만듦 | 완벽하지 않아도 OK, 방향만 있으면 다듬는 건 AI+영환 |
| 포트폴리오 PDF | B2B 신뢰 자산의 핵심 (중국 계약 등 큰 건) | 공개 가능 범위 표시 (전체공개/문의시공개/비공개) |
