# 3단계. 콘텐츠 자동화 (블로그 · 쓰레드 · 인스타/유튜브)

> 왜: 손 안 거치고(최소한만 거치고) 굴러가는 콘텐츠 채널 필요
> ⚖️ 원칙: **영상·자막·편집을 복제하지 않는다.** 소재·주제·트렌드만 가져와 **내 화면·내 말로 재창작** (저작권 안전 + 품질 ↑)

## 파이프라인 설계

```
[① 수집]                [② 선별]              [③ 재창작]                [④ 배포]
크롤링([5]번 연계)    →  주제 풀 큐레이션   →   위캔드무드 톤 창작     →   채널별 포맷 변환
- 패션 트렌드 키워드     - 주간 후보 10~20개      - brand/tone.md 주입       - 블로그: 장문+SEO
- 경쟁사/벤치마크 채널    - 선우님이 5분 내 픽      - "소재만, 표현은 새로"     - 쓰레드: 후킹 단문 체인
- 커뮤니티 반응 좋은 글   (✓/✗ 체크만)           - 초안 자동 생성            - 인스타: 캡션+해시태그
- 시즌/날씨/이슈                                                          - (유튜브: 스크립트 초안)
        └────────────────── 사람 개입은 ②픽 + ③최종검수 + ④업로드 버튼만 ──────────────────┘
```

### 단계별 구현

**① 수집 — [5] 크롤링이 입력단** ([05-skills-track.md](05-skills-track.md) §5와 한 몸)
- 소스(선우님 선정): 벤치마크 인스타/쓰레드 계정 N개, 패션 블로그/매거진 RSS, 네이버 검색 트렌드 키워드
- 구현: 주기 실행 스크립트(Python) → 결과를 마크다운 "주간 트렌드 리포트"로 정리
- ⚠️ 각 플랫폼 약관 준수 — 공개 콘텐츠의 **주제·제목·반응 수치** 수준만 수집, 본문 무단 저장·재게시 금지

**② 선별 — 사람이 5분**
- 주간 리포트에서 선우님이 "이번 주 다룰 주제" 체크 → 전문성·경험이 들어갈 수 있는 주제만 선택 (재창작 품질의 관건)

**③ 재창작 — Claude + 브랜드 컨텍스트**
- 주제 + `brand/tone.md` + 선우님 경험 메모 1~2줄 → 채널별 초안 생성
- 프롬프트 템플릿 `prompts/content/` 에 채널별로 누적 (블로그용/쓰레드용/인스타용)
- **재창작 검증 룰**: 원문과 문장 단위 유사성 없음 / 위캔드무드 실제 경험·관점 1개 이상 포함 / 출처가 '영감'인 경우도 사실관계는 재확인

**④ 배포**
- 시작: 초안을 선우님이 복붙 업로드 (운영 부담 거의 없음, 플랫폼 API 승인 불필요)
- 추후: 블로그는 자동 발행 검토 (네이버 블로그는 API 제약 → 티스토리/자체 블로그가 자동화 유리)
