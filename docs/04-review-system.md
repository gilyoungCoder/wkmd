# 4단계. 후기 · 리뷰 시스템

> 목표 기한: **7/6 (월)**
> 왜: 후기 = 카페·B2C의 신뢰 자산. **스타일링 PDF 보상**으로 후기 작성 동기 부여.

## 시스템 설계

```
[서비스 완료]          [후기 유도]               [보상 제작]              [자산화]
동행쇼핑·사진촬영  →   후기 작성 가이드 전달   →   구매한 옷 기반          →   후기 노출
완료 직후 안내          (어디에·뭘·어떻게)        스타일링 PDF 제작·발송      - 카페 후기 게시판
                       "PDF 받으려면 후기"                                  - 사이트 /b2c 하이라이트
                                                                           - 인스타 스토리/피드 재가공(3단계 연계)
```

핵심 교환: **후기 1건 ↔ "구매한 옷들로 만든 나만의 스타일링 가이드 PDF"** — 고객 입장에서 실용 가치가 커서 후기 작성 허들을 넘게 만듦.

## 구성 요소

### A. 후기 작성 가이드 (영환: 프롬프트 가이드 / 선우님: 운영)
- 고객에게 보내는 안내 1장: 작성 위치(카페 게시판), 포함 요소(전후 느낌·구체 에피소드·사진 1장 이상), 분량 가이드
- **좋은 후기를 끌어내는 질문 3개** 동봉 (자유 작성보다 질문 답변형이 품질·구체성 ↑):
  1. 받기 전 가장 고민이었던 것? 2. 과정에서 인상 깊었던 순간? 3. 주변 반응 달라진 점?
- 후기 수집용 프롬프트: 고객 답변 → 카페 게시 포맷으로 다듬는 보조 프롬프트 (고객 말투 유지, 과장 금지)

### B. 스타일링 PDF 템플릿 (영환: 템플릿 / 선우님: 건별 제작·디벨롭)
- 구성(안): 표지(고객 이름) / 이번에 구매한 아이템 맵 / 아이템별 조합 3~5룩 / 상황별 가이드(데일리·미팅·데이트) / 관리 팁 / 다음 추천(재구매 동선!)
- 2단계 진단서 PDF 템플릿과 **디자인 시스템 공유** (한 번 만들어 두 번 씀)
- 제작 보조 프롬프트: 구매 아이템 목록 입력 → 조합·상황별 가이드 초안 생성 → 선우님 감각으로 마무리

### C. 후기 → PDF 발송 흐름 (운영 규칙)
1. 서비스 완료 시 안내 멘트 (카톡 채널 템플릿)
2. 후기 확인 → 48시간 내 PDF 발송 약속 (빠른 보상 = 강한 인상)
3. 후기 스크랩: 카페 글 링크 + 스크린샷을 시트에 누적 → 사이트/인스타 재가공 소재
